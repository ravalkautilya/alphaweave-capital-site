# Data-backed homepage chart

`nvda-history-2025.json` stores 250 daily closing prices downloaded from the Yahoo Finance chart endpoint recorded in the JSON. `nvda-history-2025.svg` plots each record without smoothing or invented signals. Date range: 2025-01-02 through 2025-12-31. Currency: USD. Daily close, not adjusted close. This is a fixed historical snapshot, not live data.

`alphaweave-chart-assistant.png` was created with built-in image_gen, using the existing assistant illustration as reference.
